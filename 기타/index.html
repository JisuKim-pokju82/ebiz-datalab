기타 리서치 & 수시 보고서 아카이브

SUMMARY\기타 폴더(또는 GitHub 웹의 기타/ 폴더)에 HTML 리포트, PDF, CSV, 이미지 파일을 넣으면 자동으로 이 페이지에 카드 형태로 연결됩니다. 로컬 PC가 꺼져 있어도 GitHub 클라우드에서 상시 열람할 수 있습니다.

아카이브 스캔 중...

💡 기타 폴더에 새 자료 추가하는 2가지 방법 (PC OFF 상시 구동)

  1. 내 PC에서 올릴 때: 바탕화면 SUMMARY\기타 폴더에 파일(HTML, PDF, 엑셀 등)을 넣은 뒤 깃허브_업로드.bat을 더블클릭하면 자동으로 GitHub에 업로드됩니다.
  2. 외부/모바일에서 PC 없이 올릴 때: 우측 상단 [GitHub 기타 폴더 직접 열기] 버튼 → Add file > Upload files로 파일을 올리면 즉시 이 목록에 자동 반영됩니다.
